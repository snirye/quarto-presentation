# 🎯 Quarto Presentation Generator - Project Overview

## 📋 What We Built

A complete Python-based system that automatically generates Quarto RevealJS presentations from articles using Large Language Models (LLMs). The system takes an article as input, analyzes it with AI, creates a structured presentation outline, and generates content for each slide.

## 📁 Project Files

### Core Components
- **`presentation_generator.py`** - Main script that orchestrates the presentation generation
- **`prompt_template.md`** - Comprehensive Quarto RevealJS reference and prompt template
- **`setup.py`** - Environment setup and dependency checker
- **`requirements.txt`** - Python package dependencies

### LLM Integration
- **`llm_clients.py`** - Real LLM client implementations (OpenAI, Anthropic, Local)
- **`llm_integration_examples.py`** - Integration examples and implementation guides

### Configuration & Samples
- **`config.json`** - Configuration settings and templates
- **`.env.example`** - Environment variable template for API keys
- **`sample_healthcare_article.txt`** - Example article for testing
- **`README.md`** - Complete documentation and usage guide

### Generated Output
- **`generated_presentation_*.qmd`** - Generated Quarto presentation files

## 🚀 How It Works

### Step 1: Article Analysis
```
Article Input → LLM Analysis → Presentation Structure (JSON)
```
The system sends the article to an LLM with instructions to create a logical slide structure with specified number of slides.

### Step 2: Content Generation
```
For Each Slide:
Article + Structure + Slide Context → LLM → Slide Content (Markdown)
```
Each slide is generated individually with context about the overall presentation and adjacent slides.

### Step 3: File Assembly
```
YAML Header + Generated Slides → Complete .qmd File
```
All slides are combined with proper Quarto front matter to create a complete presentation file.
