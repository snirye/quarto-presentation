# Quarto Presentation Generator

A Python script that automatically generates Quarto RevealJS presentations from articles using Large Language Models (LLMs).

## Features

- 📄 **Article Input**: Takes any text article as input
- 🧠 **AI-Powered Structure**: Uses LLM to create logical slide structure
- 🎨 **Content Generation**: Generates detailed slide content for each slide
- 📊 **Quarto Integration**: Outputs properly formatted .qmd files
- ⚙️ **Customizable**: Adjustable slide count and output options
- 🎯 **Organized Prompts**: Centralized prompt management system

## Project Structure

```
quarto_ai/
├── presentation_generator.py      # Main generator script
├── llm_clients.py                # LLM client integrations
├── prompts/                      # Centralized prompt management
│   ├── system_prompt.md         # AI assistant role definition

├── out/                        # Generated presentations

```

## Setup

### Prerequisites

1. **Python 3.8+**
2. **Quarto** (for rendering the final presentation)
   ```bash
   # Install Quarto: https://quarto.org/docs/get-started/
   ```

### Installation

1. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Set up your LLM API keys** (choose the providers you want to use):
   
   ```bash
   # OpenAI
   export OPENAI_API_KEY="your-openai-key-here"
   
   # Anthropic Claude
   export ANTHROPIC_API_KEY="your-anthropic-key-here"
   ```
   
   **Or use a .env file:**
   ```bash
   echo "OPENAI_API_KEY=your-openai-key-here" > .env
   echo "ANTHROPIC_API_KEY=your-anthropic-key-here" >> .env
   ```

### Supported LLM Providers

The system now uses **LangChain** for unified LLM integration:

#### OpenAI Models
- `gpt-4`, `gpt-3.5-turbo`
- Requires: `OPENAI_API_KEY`

#### Anthropic Claude Models  
- `claude-3-sonnet-20240229`, `claude-3-haiku-20240307`
- Requires: `ANTHROPIC_API_KEY`

#### Local Models (via Ollama)
- `llama2`, `codellama`, `mixtral`, etc.
- Requires: Ollama installation (no API key needed)

## Usage

### Basic Usage
```bash
python presentation_generator.py your_article.txt
```

### Advanced Usage
```bash
# Generate 15 slides with custom output name
python presentation_generator.py article.txt --slides 15 --output my_presentation.qmd

# Use different model
python presentation_generator.py article.txt --model gpt-3.5-turbo --slides 25
```

### Command Line Options
- `input_file`: Path to the input article file (required)
- `--output, -o`: Output .qmd file path (optional)
- `--slides, -s`: Number of slides to generate (default: 20)
- `--model, -m`: LLM model to use (default: gpt-4)

## Workflow

1. **Structure Generation**: The LLM analyzes the article and creates a logical slide structure
2. **Content Creation**: For each slide, the LLM generates appropriate content using:
   - Original article content
   - Overall presentation structure
   - Quarto formatting reference
   - Slide-specific requirements
3. **File Generation**: All slides are combined with proper YAML front matter into a .qmd file

## Output Format

The generated .qmd file includes:
- **YAML front matter** with RevealJS configuration
- **Title slide** (automatically generated)
- **Content slides** with proper markdown formatting
- **Conclusion slide**

## Prompt Management System

The project now features a centralized prompt management system in the `prompts/` directory:

### Available Prompts

- **`system_prompt.md`** - Defines the AI assistant's role and expertise
- **`structure_generation_prompt.md`** - Template for creating presentation structure
- **`slide_content_generation_prompt.md`** - Template for generating slide content  
- **`quarto_generation_template.md`** - Complete Quarto RevealJS reference guide

### Customizing Prompts

1. **Edit prompt files directly** in the `prompts/` directory
2. **No restart required** - changes are loaded automatically
3. **Use template variables** for dynamic content:

```markdown
Generate content for slide {slide_number}.
Article: {article_content}
Structure: {structure}
```

### Using the Prompt Manager

```python
from prompts.prompt_manager import PromptManager

pm = PromptManager()
system_prompt = pm.get_system_prompt()
custom_prompt = pm.load_prompt("my_custom_prompt")
```

quarto preview generated_presentation.qmd

## Troubleshooting

### Common Issues

1. **API Key not found**
   ```
   Solution: Set appropriate API key environment variable (OPENAI_API_KEY, ANTHROPIC_API_KEY)
   ```

2. **Prompt loading errors**
   ```
   Solution: Ensure all prompt files exist in the prompts/ directory
   ```

3. **JSON parsing errors**
   ```
   Solution: Check LLM response format, may need to adjust structure generation prompt
   ```

4. **Quarto rendering fails**
   ```
   Solution: Verify Quarto installation and .qmd syntax
   ```

### Debug Mode
