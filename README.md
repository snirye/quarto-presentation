# Quarto Presentation Generator

A Python script that automatically generates Quarto RevealJS presentations from articles using Large Language Models (LLMs).

## Features

- 📄 **Article Input**: Takes any text article as input
- 🧠 **AI-Powered Structure**: Uses LLM to create logical slide structure
- 🎨 **Content Generation**: Generates detailed slide content for each slide
- 📊 **Quarto Integration**: Outputs properly formatted .qmd files
- ⚙️ **Customizable**: Adjustable slide count and output options

## Setup

### Prerequisites

1. **Python 3.8+**
2. **Quarto** (for rendering the final presentation)
   ```bash
   # Install Quarto: https://quarto.org/docs/get-started/
   ```

### Installation

1. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Set up your LLM API key** (choose one):
   
   **Option A: Environment variable**
   ```bash
   export OPENAI_API_KEY="your-api-key-here"
   ```
   
   **Option B: .env file**
   ```bash
   echo "OPENAI_API_KEY=your-api-key-here" > .env
   ```

### LLM Integration Setup

The current script includes a placeholder `LLMClient` class. To use with real LLMs:

#### OpenAI Integration
```python
import openai

class LLMClient:
    def __init__(self, api_key: str = None, model: str = "gpt-4"):
        self.client = openai.OpenAI(api_key=api_key)
        self.model = model
    
    def generate_response(self, prompt: str) -> str:
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            max_tokens=2000,
            temperature=0.7
        )
        return response.choices[0].message.content
```

#### Anthropic Claude Integration
```python
import anthropic

class LLMClient:
    def __init__(self, api_key: str = None, model: str = "claude-3-sonnet-20240229"):
        self.client = anthropic.Anthropic(api_key=api_key)
        self.model = model
    
    def generate_response(self, prompt: str) -> str:
        response = self.client.messages.create(
            model=self.model,
            max_tokens=2000,
            messages=[{"role": "user", "content": prompt}]
        )
        return response.content[0].text
```

## Usage

### Basic Usage
```bash
python presentation_generator.py sample_healthcare_article.txt
```

### Advanced Usage
```bash
# Generate 15 slides with custom output name
python presentation_generator.py article.txt --slides 15 --output my_presentation.qmd

# Use different model
python presentation_generator.py article.txt --model gpt-3.5-turbo --slides 25
```

### Command Line Options
- `input_file`: Path to the input article file (required)
- `--output, -o`: Output .qmd file path (optional)
- `--slides, -s`: Number of slides to generate (default: 20)
- `--model, -m`: LLM model to use (default: gpt-4)

## Workflow

1. **Structure Generation**: The LLM analyzes the article and creates a logical slide structure
2. **Content Creation**: For each slide, the LLM generates appropriate content using:
   - Original article content
   - Overall presentation structure
   - Quarto formatting reference
   - Slide-specific requirements
3. **File Generation**: All slides are combined with proper YAML front matter into a .qmd file

## Output Format

The generated .qmd file includes:
- **YAML front matter** with RevealJS configuration
- **Title slide** (automatically generated)
- **Content slides** with proper markdown formatting
- **Conclusion slide**

## Rendering the Presentation

After generating the .qmd file:

```bash
# Render to HTML
quarto render generated_presentation.qmd

# Open in browser
quarto preview generated_presentation.qmd
```

## Customization

### Modifying the LLM Prompts

Edit the prompt templates in `presentation_generator.py`:

- **Structure prompt**: `generate_structure()` method
- **Slide content prompt**: `generate_slide_content()` method

### Changing Output Format

Modify the YAML front matter in the `generate_presentation()` method to customize:
- Theme (default, dark, beige, etc.)
- Transitions and animations
- Code highlighting
- Interactive features

### Adding Custom Slide Types

Extend the slide generation logic to handle special slide types:
```python
def generate_special_slide(self, slide_type: str, content: str) -> str:
    if slide_type == "code_demo":
        return self._generate_code_demo_slide(content)
    elif slide_type == "image_gallery":
        return self._generate_image_gallery_slide(content)
    # Add more custom types
```

## Troubleshooting

### Common Issues

1. **API Key not found**
   ```
   Solution: Set OPENAI_API_KEY environment variable or create .env file
   ```

2. **JSON parsing errors**
   ```
   Solution: Check LLM response format, may need to adjust prompts
   ```

3. **Quarto rendering fails**
   ```
   Solution: Verify Quarto installation and .qmd syntax
   ```
